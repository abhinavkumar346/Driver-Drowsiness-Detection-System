# Driver-Drowsiness-Detection-System
A real-time drowsiness and yawn detection system that combines YOLO face detection (for locking onto a single face in the frame) with MediaPipe Face Mesh (for fine-grained landmark tracking) to compute EAR (Eye Aspect Ratio), MAR (Mouth Aspect Ratio), and PERCLOS — the three core signals used to flag closed eyes, yawning, and sustained drowsiness.
